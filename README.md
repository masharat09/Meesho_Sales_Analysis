Meesho Sales Analysis Dashboard

A complete sales analysis dashboard project built using Power BI to analyze Meesho sales data and generate meaningful business insights through interactive visualizations and KPI tracking.

📌 Project Overview

This project focuses on analyzing Meesho sales performance using Power BI.
The dashboard helps in understanding:

    Sales performance
    Profit analysis
    Category-wise sales
    State-wise performance
    Order trends
    Customer insights
    KPI metrics

The main goal of this project is to convert raw sales data into interactive and easy-to-understand business insights.

    📊 Dashboard Features
    📈 Total Sales Analysis
    💰 Profit & Revenue Tracking
    🛒 Product Category Performance
    🌍 State-wise Sales Distribution
    📅 Monthly & Yearly Trends
    📦 Order Quantity Analysis
    📌 Interactive Filters & Slicers
    📊 KPI Cards and Charts

🛠️ Tools & Technologies Used
